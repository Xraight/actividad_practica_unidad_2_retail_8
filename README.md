**Descripción del Proyecto**
Este repositorio contiene el diseño y la arquitectura de un Data Mart de Ventas para "Casa&Estilo", una empresa de retail especializada en muebles, decoración y artículos para el hogar[cite: 1]. El objetivo principal es consolidar la información operativa para permitir el análisis histórico de ventas y el cumplimiento logístico de entregas[cite: 1].

## 📂 Estructura del Repositorio
- Reporte y presentación de los entregables
- Codigo .sql del Script DLL solicitado
- Archivo .drawio del diagrama ER solicitado

## 🛠️ Tecnologías y Herramientas
*   **Bases de Datos:** PostgreSQL (Script DDL)
*   **Modelado Visual:** draw.io
*   **Enfoque de Diseño:** Modelado Dimensional (Esquema Estrella)
